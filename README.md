# FORMA Detailing — многостраничный сайт

Учебный проект индивидуального задания №8: сайт коммерческой услуги с потенциалом дальнейшего SEO-продвижения.

## Тематика
Детейлинг автомобилей: полировка кузова, керамическое покрытие и химчистка салона. Услуги имеют сформированный спрос и конкурентов в поисковой выдаче.

## Страницы
- `index.html` — главная страница;
- `services.html` — обзор услуг;
- `ceramic.html` — посадочная страница «Керамическое покрытие автомобиля»;
- `polishing.html` — посадочная страница «Полировка кузова автомобиля»;
- `interior.html` — посадочная страница «Химчистка салона автомобиля».

## Реализованные компоненты
- Семантическая структура HTML5 и один H1 на каждой странице.
- Отдельные SEO title и description.
- Контентные блоки с текстом и изображениями на каждой странице.
- Карточки услуг.
- Карусель на главной странице с кнопками переключения.
- Модальное окно с формой заявки.
- Адаптивная навигация и мобильная кнопка записи.
- Адаптивная сетка на CSS Grid и Flexbox.

## Запуск
Проект статический. Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

После запуска откройте http://localhost:8000

## Важно
Название студии, адрес, телефон и цены вымышлены и используются для демонстрации макета. Форма не подключена к серверу и не отправляет реальные заявки. Изображения загружаются с Unsplash.

Перед публикацией и SEO-продвижением необходимо согласовать тематику с преподавателем, проверить поисковый спрос через Яндекс Wordstat и заменить демонстрационные контактные данные.
